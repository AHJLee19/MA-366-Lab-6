# MA-366 Lab 6

A Jupyter Notebook.

## Setup

1. Open the project folder (containing the `.ipynb` and `.txt` files) in an editor like **Visual Studio Code**.
2. Install the required packages by running the following in that folder:

   ```bash
   pip install -r requirements.txt
   ```

3. Make sure the selected kernel is the version of Python installed on your machine.
4. Run all cells.

## Notes

- For individual edits, you can run individual cells instead of the whole notebook.
